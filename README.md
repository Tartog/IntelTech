## Задание
Сделать простой визуализатор погоды. 
Время выполнения: 1-3 часа (+время на разобраться с Vaadin)
На экране два текстовых поля для ввода координат и одна кнопка “показать погоду”.
С помощью https://openweathermap.org/current получать информацию о погоде в месте по координатам от пользователя. При нажатии на кнопку отображать погоду + тематическую картинку (по желанию). 
![image](https://github.com/user-attachments/assets/51078c5c-e997-43ef-8a61-85c093d90ef6)
Чтобы получить токен: https://openweathermap.org/price -> free access -> free for everyone.
По умолчанию погода в Кельвинах, в параметрах запроса можно указать метрическую систему.
По умолчанию  описание на английском, в параметрах запроса можно указать язык.
Оформление на ваше усмотрение.
## Запуск
1) Открыть в консоли папку с проектом
2) Ввести mvn clean install
3) Ввести mvn spring-boot:run
